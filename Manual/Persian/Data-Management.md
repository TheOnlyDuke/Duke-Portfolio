# راهنمای مدیریت داده‌ها

## خلاصه

`src/data/portfolio-data.ts` منبع واقعی تمام اطلاعات است که در وب‌سایت پورتفولیو نشان داده می‌شود. این فایل شامل پروفایل، هِرو، مهارت‌ها، پروژه‌ها، پژوهش، تجربه، انتشارات، تحصیلات، سفر، تماس و چند متد کمکی است.

### محل ذخیره

```
src/data/portfolio-data.ts
```

### ساختار

شی‌ء صادرشده `portfolioData` شامل کلیدهای بالادست زیر است. هر کلید داده‌ای را دارد که در سایت نمایش داده می‌شود.

- **profile** – جزئیات شخصی (نام نمایش، نام کامل، لوگوی، حوزه‌های تمرکز، مکان، ایمیل، شبکه‌های اجتماعی)
- **hero** – متن الهیٔ hero (عنوان، زیرعنوان، دکمه‌ها)
- **skills** – آرایه‌ای از گروه‌های مهارت؛ هر گروه شامل آرایه‌ای از اشیای `name`/`kind`
- **projects** – آرایهٔ پروژه‌ها (slug, name, tagline, description, role, tech, etc.)
- **research** – آرایهٔ پژوهش‌ها (slug, title, area, problem, approach, methods, status, period, role, results, links)
- **experience** – آرایهٔ تجربه (type, org, role, period, summary, highlights)
- **publications** – آرایهٔ انتشارات (title, venue, year, placeholder)
- **education** – آرایهٔ تحصیلات (type, org, role, period, summary)
- **journey** – رویدادهای طولانی‌مدت (year, title, venue/organization, placeholder)
- **contact** – ایمیل، مکان، شماره، آدرس
- **universityActivities** – فعالیت‌های دانشگاهی (org, role, period, summary)
- **getFocusAreasDisplay()** – متدی کمکی که سه برچسب اول حوزه تمرکز را به‌هم می‌چسباند.

**قواعد قالب‌بندی**

- پرانتزهای `{}`/`[]` باید مطابقت داشته باشند.
- رشته‌ها با نقل قول ""‌تخته شده باشند.
- کاماهای پایانی اختیاری‌اند و مجازند.
- برای لینک‌های گمشده از `null` استفاده کنید.

### نکات ویرایش

1. از ادیتور کد برای باز کردن فایل استفاده کنید؛ اندازهٔ کوچک فایل اجازهٔ ویرایش خط به خط می‌دهد.
2. ساختار آرایه را حفظ کنید؛ فقط آیتم‌های جدید را داخل آرایه اضافه/حذف کنید.
3. رشته‌ها را معتبر کنید (همه در "" باشند). برای متن چند خطی می‌توانید از الگوی فراگیر (`` `text` ``) استفاده کنید ولی "" ساده‌تر است.
4. بعد از هر تغییر با اجرای `npm run dev` تغییرات را در سایت بررسی کنید.
5. برای تغییرات زیاد یک نسخهٔ پشتیبان ایجاد کنید.

### مثال تغییر

اگر می‌خواهید ایمیل از `DukeMahdinal@gmail.com` به `mahdim@duke.edu` تغییر کند:

```ts
email: "mahdim@duke.edu",
```

اضافه کردن یک پروژهٔ جدید:
شما دو روش دارید:

۱. **ویرایش دستی** – مستقیماً آیتم‌های پروژهٔ جدید را در آرایه `projects` داخل `src/data/portfolio-data.ts` اضافه، ویرایش یا حذف کنید.  
۲. **برنامه‌نویسی** – از متدهای استاندارد آرایه جاوااسکریپت (مانند `push()`، `splice()`، `filter()`) اگر ترجیح می‌دهید به‌صورت برنامه‌ریزی شده لیست را دستکاری کنید.

`push()` فقط یک متد استاندارد آرایه جاوااسکریپت است؛ استفاده از آن اختیاری است و برای ویرایش دستی لازم نیست.

```ts
projects.push({
  slug: "new-project",
  name: "My New Project",
  tagline: "یک توضیح کوتاه",
  description:
    "توضیح کامل در اینجا. تمام فیلدهای موجود در ساختار واقعی پروژه را شامل کنید.",
  role: "Lead Developer",
  tech: ["React", "Next.js"],
  year: 2026,
  status: "Active",
  links: {
    github: "https://github.com/your/repo",
    demo: "https://demo.example.com",
  },
  domain: "Web",
});
```

### نکات کلیدی

- تمام داده‌های سایت در این فایل واحد است.
- هیچ API، دیتابیس یا پس‌زمینهٔ سرور وجود ندارد؛ کارهای کامپایل در زمان build انجام می‌شود.
- در آینده UI برای ویرایش اضافه خواهد شد؛ پس از آن این راهنما به فرم فرم وب جایگزین می‌شود.
