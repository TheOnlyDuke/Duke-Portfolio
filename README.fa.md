# پورتفولیوی مینیمال تحقیق و توسعه (R&D)

یک وب‌سایت سبک و بدون نیاز به پیکربندی (zero‑configuration) بر پایه Next.js که به عنوان پایه‌ای برای تحقیقات سریع و دموهای محصول عمل می‌کند.

## ✨ ویژگی‌ها
- **راه‌اندازی سریع** – آماده‌سازی در کمتر از ۲ دقیقه.
- **بیلد بدون پیکربندی** – تمامی ابزارهای بیلد برای محیط Production بهینه‌سازی شده‌اند.
- **رابط کاربری مبتنی بر کامپوننت** – تمامی کامپوننت‌های React در `src/components` قرار دارند تا به راحتی قابل بازاستفاده باشند.
- **ابزارهای توسعه** – استفاده از ESLint برای استایل، Prettier برای فرمت‌بندی و محیط توسعه TypeScript برای مهاجرت‌های آتی.
- **آماده برای سیستم طراحی** – قدرت گرفته از Material‑UI v9 + Emotion، آماده برای اعمال هرگونه Theme.

## 🛠️ پشته تکنولوژی (Tech stack)
- **فریم‌ورک**: Next.js 16.3+ (app router، پشتیبانی از TypeScript، بهینه‌سازی تصاویر)
- **رابط کاربری (UI)**: React 19, MUI v9, Emotion
- **ابزارها**: ESLint, TypeScript (dev), Node 18+ (توصیه‌شده)
- **لینتینگ و فرمت‌بندی**: ESLint

## 📁 ساختار پروژه
```
├─ src
│  ├─ app        # صفحات app router در Next.js
│  ├─ components # اجزای رابط کاربری (UI primitives) قابل استفاده مجدد
│  ├─ data       # قطعات JSON برای داده‌های دمو
│  ├─ theme      # تنظیمات تم MUI + Emotion
│  └─ assets
└─ public
```

## 🚀 شروع سریع
```bash
# کلون کردن مخزن
git clone https://github.com/TheOnlyDuke/Duke-Portfolio.git
cd Duke-Portfolio

# نصب وابستگی‌ها
npm install

# اجرای محلی
npm run dev
```
برای پیش‌نمایش، آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## 📦 بیلد / استقرار (Deploy)
```bash
npm run build
npm start # یا
npx serve out
```

> وب‌سایت در قالب یک دایرکتوری استاتیک `out/` خروجی می‌دهد؛ هر سرویس میزبانی که از فایل‌های استاتیک پشتیبانی کند، برای این پروژه مناسب است.

## 🔧 سفارشی‌سازی پورتفولیو
شما نیازی به تغییر کدهای منبع برنامه ندارید. تمام محتوای پروفایل، تحصیلات، تجربه، مهارت‌ها، پروژه‌ها، پژوهش، انتشارات و مشخصات تماس در یک فایل داده قرار دارد:

`src/data/portfolio-data.ts`

با ویرایش این فایل، اطلاعات خود را به‌روزرسانی کنید. اپلیکیشن به‌صورت خودکار تغییرات را نمایش می‌دهد.

> **بهبود آتی:** رابط کاربری مدیریت محتوا در برنامه در حال توسعه است، نوشتن داده‌ها را بدون حذف فایل داده ساده‌تر می‌کند.

دستورالعمل کامل برای ساختار فایل و نحوه سفارشی‌سازی هر بخش را می‌توانید در مستندات زیر مشاهده کنید:
[📖 راهنمای مدیریت داده‌ها](Manual/Persian/Data-Management.md)

## 📄 لایسنس
این مخزن تحت لایسنس **Apache 2.0** منتشر شده است – شما می‌توانید آن را کپی کرده، تغییر دهید یا در پروژه‌های خود به کار ببرید.

اگر از این مخزن در پورتفولیو یا مقاله‌ای استفاده می‌کنید، لطفاً یک ارجاع کوتاه اضافه کنید، به عنوان مثال:

```text
Portfolio powered by Duke‑Portfolio (https://github.com/TheOnlyDuke/Duke-Portfolio)
```
